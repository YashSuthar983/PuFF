YASH SUTHAR / CLOUD KIT

A sky for anything.

Move over the sky or tap to light the clouds from within. Try different atmospheres and shapes.

Cloud text is one shape. A density field can describe any volume.

Use the library
const sky = new CloudKit.CloudScene(canvas, {
  preset: 'storm', quality: 'medium'
});
// Bring your own cloud shape:
const field = CloudKit.createDensityField(
  (x,y,z) => yourDensity(x,y,z)
);
sky.setDensityField(field.data, field);
