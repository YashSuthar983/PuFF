# Rock surface source

Dark Rock by Amal Kumar / Poly Haven, CC0.

- Asset: https://polyhaven.com/a/dark_rock
- License: https://polyhaven.com/license
- Original local source: `/home/yash/Downloads/dark_rock_1k.blend/textures/`

The user's local diffuse, OpenGL normal, roughness, and displacement maps were converted to browser-friendly formats. No photogrammetry mesh was included in this material download. The demo creates a displaced ridge mesh and uses these scanned maps for surface detail and lighting.

This is a Poly Haven scanned material. It is not a Quixel Megascans asset.
